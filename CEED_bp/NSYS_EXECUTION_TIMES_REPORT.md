# CEED BP3 (`bp3_opt`) System-Level Execution Times & Nsight Systems Report (`p = 1..8`, `1,000`–`1,000,000` DoFs)

**Target Executable**: `./build/bp3_opt <p> 1000 1000000` (1 MPI Rank / 1 GPU, Release `-O3`, `sm_89`, `fp64`)  
**Polynomial Orders Profiled**: $p = 1, 2, 3, 4, 5, 6, 7, 8$ ($Q_1 \dots Q_8$ 3D Hexahedral Finite Elements, Gauss Quadrature $n_q = p + 2$)  
**DoF Range**: `1,000` to `1,000,000` DoFs (`82` active benchmark cycles total across $p = 1 \dots 8$)  
**Hardware & Profiler Stack**: NVIDIA RTX 1000 Ada Generation Laptop GPU (`20` SMs, `6,141 MiB` VRAM, Driver `595.99.02`, CUDA `13.2`), Intel Core Ultra 7 155H (`22` threads), `deal.II 9.7.1`, `Kokkos 5.0.99`, **NVIDIA Nsight Systems `2025.6.1`**  
**Infrastructure Constraint**: **Zero source-code or build modifications** (`0` bytes diff across `src/`, `include/`, `tests/`, and `CMakeLists.txt`).

---

## Methodology

To obtain both **distortion-free wall-clock timings** and **exact system-level operation attribution** without touching any C++ or Kokkos code, two complete passes were executed across all 8 polynomial degrees ($p = 1 \dots 8$) for `min_size = 1000`, `max_size = 1000000`:

1. **Uninstrumented Native Pass**: `./build/bp3_opt <p> 1000 1000000` executed directly with no profiler attached (`332.42 s` cumulative wall time across $p = 1 \dots 8$) to record exact per-cycle wall and CPU times for [`setup_dofs`](src/bp3_opt.cc#L133-L160), [`setup_matrix_free`](src/bp3_opt.cc#L164-L183), [`compute_rhs`](src/bp3_opt.cc#L187-L201), `10` repetitions of [`SolverCG::solve`](src/bp3_opt.cc#L230-L257), `5 x 200` standalone [`do_matvec`](src/bp3_opt.cc#L260-L283) calls, and `3 x 5 x 200` [`matvec_ghost_timing`](src/bp3_opt.cc#L304-L380) calls.
2. **Nsight Systems System-Level Pass**: `nsys profile --trace=cuda,osrt --sample=none` followed by `nsys export --type sqlite` and `nsys stats` across all 8 polynomial degrees, capturing every GPU operation (`CUPTI_ACTIVITY_KIND_KERNEL`), memory transfer (`CUPTI_ACTIVITY_KIND_MEMCPY`), memory zero-fill (`CUPTI_ACTIVITY_KIND_MEMSET`), CUDA Runtime API call (`CUPTI_ACTIVITY_KIND_RUNTIME`), and per-cycle timeline phase boundary (segmented deterministically via the single `ConstantRhsKernelFunctor` launch per cycle).
